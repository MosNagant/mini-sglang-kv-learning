## 怎样理解最终决定

1-warp没有稳定收益；grouped在部分较大B有局部改善，但小B退化、对原版结果不稳定；full_groups的代码简化没有转成稳定收益。36进一步说明内存条件能够改变编译产物，但也不能从一次计时波动反推瓶颈。37按旧数据冻结规则，候选须每轮耗时都不高于原版97%才具备晋升资格，当前无人入选。

37号的3%门槛是看过历史结果后作出的保守工程筛选标准，在新36/37运行前冻结；不能回称27/30/32/35事前已注册该门槛。36的条件变化门槛另有运行前设计。两者都不是显著性检验。默认保留原版，不代表原版在所有形状都最优；显式研究候选仍可查看和复现。没有根据36/37结果重新调门槛，也没有将重复测量中最好的一轮当作最终成绩。

## 支持范围和证据边界

实测环境为RTX4070Ti、Torch2.9.1+cu128、Triton3.5.1，上游固定`9a91cfafe754aa85daee49998176275667eb58f2`。合同以FP16 K/V、int32唯一合法indices、列距1及选定宽度/行距/布局为限；各报告列出自己的确切B/D/C，不能把一个run的通过扩大到任意布局。

Graph为主要计时政策，Eager单列；首次编译、预热、完整检查与存档在计时外。公开入口的校验成本不混入预验证raw launch。重复地址或四套轮换都不是冷DRAM极限测试。没有本次NCU运行时计数器、AMD实机、模型tokens/s、请求P99或整模型加速结论。

M07的融合方向停在真实调用前置评估：M08尚未确认完整实际调用链，不以脱离模型的演示冒充项目融合收益。它是明确的后续依赖，不影响现有算子研究版本收尾。
