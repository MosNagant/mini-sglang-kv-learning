## 4. 学习中心固定在什么地方

当前项目继续是：**基于 mini-sglang 的 KV Cache 写入算子实现、正确性验证与性能分析。**

它要回答四个可以由代码和数据证明的问题：

1. 输入的数据应该写到哪里，原版具体怎样完成？
2. 我能否亲手写出同一操作，并证明目标写对、其他位置没被破坏？
3. 在明确条件下，它到底花多少时间，测量是否可靠？
4. 根据证据改变实现后，哪些输入变快、哪些变慢，为什么？

**算子开发、GPU 性能分析、计算相关 GPU 软件**是优先保持的岗位范围。这是项目复用策略，不是声称三类岗位的所有要求完全一样。
