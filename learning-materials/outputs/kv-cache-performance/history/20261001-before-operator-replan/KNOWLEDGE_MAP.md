# AI Infra 必修地图：以 GPU 性能与单卡推理为主线

最后更新：2026-09-30。学习目的：用户能从自己的代码和实验解释问题，再把方法迁移到其他算子与平台。

AI Infra 范围包括训练、推理、运行时、硬件、编译、通信与服务工程。四周目标是建立完整的基础地图，并在单卡推理和 GPU 性能上做到实操；不把本项目完成等同于掌握整个领域。岗位的具体要求仍需日后结合实际招聘说明校准。

## 本项目学习深度的边界

09-30用户询问知识要学到哪一层。主线是CUDA内核与GPU性能分析，向上理解并验证它在单卡推理里的作用，向下理解解释测量所需的GPU执行与存储机制。边界按能完成和解释项目来划分，不按“看懂一个copy调用即结束”划分。

用户随后澄清要的是从底层到大模型的层次位置，而非横向知识清单。教学用粗略层次（从底到上）：芯片电路实现→GPU执行与存储结构→CUDA运行时及C++内核→推理框架→大模型推理过程→聊天应用。向上学习到“大模型推理过程”：能解释从token输入到生成下一token的主要计算、跑通真实模型并验证局部优化的整体影响。CUDA内核与性能实验是最深入层；框架和模型推理层理解相关路径并实测。芯片电路设计与聊天产品开发不作为本项目主线。训练和新模型结构研发是另一个方向，不能误画成推理过程之上的必经层。

| 层次 | 本项目需要的深度 |
| --- | --- |
| 模型与推理背景 | 能解释Q/K/V、attention、KV缓存、prefill/decode和生成token之间的关系；本月不实现模型预训练或设计新模型结构 |
| 推理框架与接口 | 能追踪Python→JIT/FFI→C++启动→CUDA，解释真实数据布局、调用开销和缓存位置；后期运行单卡模型比较整机指标 |
| CUDA C++内核 | 核心深入：亲手实现线程分工、指针/步长、读写、边界处理；能在换尺寸和布局后重新推导，而非仅复述当前代码 |
| GPU执行与存储 | 理解warp/block/SM、访存合并、对齐、寄存器及缓存等与当前瓶颈有关的机制；依据可获得证据分析，不要求芯片电路设计 |
| 实验与性能工程 | 核心深入：独立正确性验证、计时边界、重复微基准、profiler解释、假设验证、回退与复现；结果未达挑战目标也如实报告 |

训练系统、多GPU、编译器后端和生产集群保留基础地图与迁移意识，不在本项目内扩成额外实现任务。项目验收要能回答“为什么这样写、怎么证明正确、时间测的是什么、瓶颈证据是什么、整机影响多大”。这不是宣称已经掌握全部AI Infra。

## 掌握标准

| 状态 | 含义 |
| --- | --- |
| 未学 | 尚未针对该问题学习 |
| 已讲待验证 | 看过解释，尚无独立回答或实验依据 |
| 能解释具体例子 | 用户能从例子推导，但未证明能推广 |
| 能独立做 | 能写、跑、排错并用结果解释 |
| 能迁移与应对追问 | 换尺寸、布局、实现或反例后仍能推导，并说明适用范围 |

不把整个领域压成一个“掌握百分比”。对每一条验收保留具体问答、代码或数据；工具安装成功不提高知识等级。

## 参考资料与使用边界

- PyTorch 2.9 的 [CUDA semantics](https://docs.pytorch.org/docs/2.9/notes/cuda.html)：用于异步执行、streams、同步与 CUDA Graph 的学习，版本贴近当前 torch 2.9.1。不据此自动升级环境。
- Hugging Face 的 [How caching works](https://huggingface.co/docs/transformers/main/cache_explanation)：用于理解 KV 的缓存用途。文档 main 不代表本机 transformers 版本。
- NVIDIA 的 [Nsight Compute Profiling Guide](https://docs.nvidia.com/nsight-compute/ProfilingGuide/index.html)：用于指标含义、采集开销与分析方法；网页可能更新，具体 CLI 和可用指标以本机 2025.1.1 输出为准。
- SGLang 的 [Production Metrics](https://docs.sglang.io/docs/references/production_metrics)：作为服务指标概念参考，不声称 mini-sglang 固定提交具有全部同名能力。
- AMD 的 [HIP programming model](https://rocm.docs.amd.com/projects/HIP/en/latest/understand/programming_model.html)：用于平台对照，不能替代实际 AMD 硬件验证或兼容性检查。
