## 接回源码

store.cu第43行以warp_id读取pos=indices[warp_id]；第45行将源K行起点设为k+warp_id×kv_input_stride，第44行将目标K行起点设为k_cache+pos×kv_cache_stride。主机端第96–97行已把stride换成字节。

warp.cuh第56–57行以j=i×32+lane_id索引Package；本次j=lane_id，每包8字节。因此单个线程复制的起始位置为：

```text
源K起点 + 输入行号×256字节 + lane_id×8字节
目标K缓存起点 + 目标行号×512字节 + lane_id×8字节
```

源和目标的基址不同；比较的是各自内部的字节偏移，不比较两块内存的裸指针数值。下标和字节必须区分，不能把lane_id直接作为字节偏移，也不能在已转为字节的stride上再乘2。
