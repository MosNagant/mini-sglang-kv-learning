## 核验内容

上游commit固定为9a91cfafe754aa85daee49998176275667eb58f2；GPU为RTX 4070 Ti，PyTorch 2.9.1+cu128，Triton 3.5.1。保存的源码确为：

cols = tl.arange(0, WIDTH)
src_offsets = pid * SRC_ROW_STRIDE + cols
dst_offsets = pos * DST_ROW_STRIDE + cols
~~~

| 原版CUDA | 64 | 64 | 128 | PASS |
| 原版CUDA | 128 | 128 | 256 | PASS |

启动器读取实际shape/stride，Triton grid=(3,)、num_warps=4。两宽度使用同一份源码，参数为constexpr，可产生不同编译特化；不能据此宣称相同机器码。

独立离线重建K=10+pid*D+col、V=K+1000，并按indices=[7,0,3]生成完整期望缓存：目标缓存2304个标量、未写缓存3840个标量均吻合；输入2304个标量和12个索引值保持不变。四例共6144个缓存标量，无差异。源码清单22项SHA256全匹配；内核SHA256为83d89e371d1dfcb44e59f4cadcd8e7ef34f9997b0b0b8cf7000ef1a25f368cf2。

检查器每个宽度接受1个正确fixture、拒绝7个故意错误（3行K与3行V分别破坏末列，以及颠倒目标映射），合计2正例、14反例。CPU控制与4个GPU用例分别统计；不意味着检测所有错误类型。
