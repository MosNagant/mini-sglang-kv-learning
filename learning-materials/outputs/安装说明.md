## 安装与修复记录

Windows build 为 22621.1702（Windows 11 22H2），虚拟机平台已启用，Windows 启动项 `hypervisorlaunchtype` 为 `Auto`。

原先下载 WSL 返回 HTTP 403，已通过校验微软签名及 SHA-256 的官方本地 MSI 完成安装。随后 Ubuntu 创建虚拟机时出现 `CreateVm/HCS/ERROR_PATH_NOT_FOUND`，已恢复缺失的 Hyper-V 虚拟磁盘服务设备并成功安装 Ubuntu。具体证据和修复结果见同目录的《故障定位与修复说明.md》。

`Start-WSL-Setup.cmd` 和 `Install-WSL.ps1` 保留作为安装入口，需要时在平时登录的 Windows 账户中以管理员身份运行。脚本使用 `packages` 内的官方 WSL MSI，联网安装 Ubuntu，并验证启动、GPU 可见性和 DNS。已有发行版不会被注销或删除；脚本不会自动重启电脑、覆盖 `.wslconfig` 或转换旧发行版。若提示 **RESTART REQUIRED**，保存工作并手动重启后再运行。

安装与修复日志保存在同目录的 `logs` 文件夹。

最初的 WSL 安装脚本不包含 CUDA Toolkit；后续 CUDA 入口已完成环境配置和运行验证。WSL 中使用 Windows 显卡驱动映射的 CUDA 接口，不要安装 `nvidia-driver-*`、`cuda-drivers` 等 Linux 驱动包。示例项目已存放在 Ubuntu 的 `~/projects/cuda-starter` 中。

官方依据：[Microsoft WSL 安装文档](https://learn.microsoft.com/windows/wsl/install)、[NVIDIA CUDA on WSL 指南](https://docs.nvidia.com/cuda/wsl-user-guide/)。
